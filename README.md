# Career Assessment MVP

Streamlit + PostgreSQL/SQLite architecture for a first 50-student pilot.

## Run
pip install -r requirements.txt
streamlit run app.py

For hosted concurrent use, set DATABASE_URL to a managed PostgreSQL/Supabase database. SQLite is for local development.

The sample bank is deliberately small. Replace it with the production 800–1,200 item bank and blueprint engine before commercial use.
