# 50-student pilot

Use Streamlit + managed PostgreSQL/Supabase. SQLite is only for local development.

For the production assessment, expand to 800–1,200 questions and 80+ questions per attempt. Use blueprint-based selection by domain, construct and difficulty rather than pure randomization. Keep question-family IDs so equivalent forms can be generated and previous questions excluded on retakes.

Before calling the assessment psychometrically validated, run proper reliability/validity and item-analysis studies on an appropriately sampled dataset.
